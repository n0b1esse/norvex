# Norvex — исходные файлы

Astro frontend и исходные прикладные скрипты Directus. Git-история, старый remote
и личный GitHub PAT прежнего разработчика не включены.

- `src/` — страницы, компоненты, стили, переводы и обращения к CMS.
- `public/` — статические ресурсы.
- `scripts/` — синхронизация favicon при сборке; `test/` — её тесты.
- `directus/` — существовавшие скрипты схемы, контента и интеграций CMS.
- `deploy/` — файлы из прежней кодовой базы с Oracle-специфичными настройками;
  фактический экспорт прежнего сервера находится в `../server/config/`.
- `package.json` и `package-lock.json` — команды проекта, зависимости и версии.
- `.env.example` — `DIRECTUS_URL`; localhost — адрес тестирования, не production.
- `.vercel/project.json` — идентификаторы клиентского проекта, исключены из Git.

Сайт статический, контент поступает из Directus во время сборки. Изображения,
заявки и аналитика также связывают браузер с CMS. Автопубликация через личный
GitHub разработчика не входит в передаваемую БД. Организация нового репозитория
и размещения остаётся за новым администратором.

Описание прежней инфраструктуры: [OVERVIEW.md](../OVERVIEW.md).
Проверки и ограничения: [AUDIT.md](../AUDIT.md).
Данные и доступы находятся вне этого каталога и не предназначены для GitHub.
Пять локальных вариантов изображений сохранены в `../local-uncommitted-assets/`.

Существовавшая техническая документация в `FRONTEND.md`, `directus/README.md`
и `docs/` сохранена как исторический материал. Она может ссылаться на прежние
сценарии и не является актуальной пошаговой инструкцией нового деплоя.
