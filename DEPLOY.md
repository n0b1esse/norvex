# NORVEX — DEPLOY.md

Корпоративный сайт norvexhse.com. Astro (статика) + самописная PHP-админка на Hoster KG (Apache+nginx, PHP 7.2, MySQL 8).

## Структура

```
src/            — Astro-страницы, компоненты, i18n, оверлей live-контента
public/         — статические файлы (туда попадают в dist/ как есть)
php/            — серверный слой: api.php, send-inquiry.php, admin/, config.example.php
dist/           — собранный сайт (НЕ в git, создаётся сборкой)
```

## Сборка

```bash
npm ci
npm run build   # → dist/
```

Дальше PHP-слой копируется в корень dist (это делает `build_site.py` из рабочей папки или вручную: `cp -r php/* dist/`).

## Секреты (важно)

- `php/config.php` — **не в git**, не в архивах. Содержит реквизиты БД.
- Шаблон — `php/config.example.php` (скопировать в `config.php`, заполнить).
- Разовые скрипты (`import-seed.php`, `migrate-*.php`, install и т.п.) в репозиторий не включены и на сервере удаляются после выполнения.

## Деплой (ручной, через ISPmanager)

1. `npm ci && npm run build`
2. Собрать архив содержимого `dist/` (включая php/)
3. Залить в `/www/norvexhse.com/` на хостинге (ISPmanager → Менеджер файлов → распаковать)
4. Проверить: главная 200, /ru, форма (тестовая заявка → письмо владельцу), /admin/ (редирект на логин)
5. После деплоя удалить разовые скрипты, если они заливались

## Live-контент (без пересборки)

Все тексты/галереи/FAQ размечены атрибутами `data-c*` / `data-live-*`; правки из админки (`/admin/` → «Тексты», «FAQ», «Новости» и т.д.) подхватываются в браузере при загрузке страницы. Пустая БД = статический фолбэк (сайт не ломается).

## Карты сайта

- `sitemap-index.xml` (генерирует Astro), `robots.txt` — в сборке
- `news-sitemap.php` — PHP, все опубликованные статьи; указан в robots.txt
